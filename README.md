# Jobify

**A personal job board that collects software internship postings in Montreal and New York and ranks them, so finding the right ones takes minutes instead of hours.**

Internship postings are scattered across hundreds of company career pages and community lists. Jobify checks those places automatically several times a day, removes duplicates, and keeps only roles in Montreal (including nearby suburbs), New York, or remote within Canada. It then gives each posting two scores: how good a fit it is for me, and how good the internship itself looks (pay, mentorship, real work). It does not apply to anything; it just builds the list, and a person does the applying.

It was built for my own Summer 2027 internship search. An earlier version tried to apply to jobs automatically, but it only worked on a handful of simple forms, so that part was removed.

## What you can do with it

- See one list of internship and new-grad postings gathered from many job sites and company career pages.
- Sort by "chance" (how likely an application is to land) or "quality" (how good the role looks).
- Filter in one click: Montreal, New York, remote, Summer 2027, new in the last 24 hours, not yet applied.
- See which hiring season a posting is for, and whether it says anything about visa sponsorship.
- Get a suggestion for which version of the résumé to send for each posting.
- Get a short message (on Slack or Telegram) when promising new postings appear.
